## ⚡ Quick Start / Local Development

```bash
# 1. Clone the repository
git clone https://github.com/orondee/Test-Websites.git

# 2. Enter directory
cd Test-Websites

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your web browser.

## 📦 How to Turn into a Live GitHub Pages Link

To host this website on GitHub's free hosting with your own `https://orondee.github.io/Test-Websites/` link:

### Option A: Via GitHub Actions (Recommended)

1. Open your repository on GitHub: [https://github.com/orondee/Test-Websites](https://github.com/orondee/Test-Websites).
2. Go to **Settings** > **Pages** (under Code and automation).
3. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
4. GitHub will automatically detect the Vite / static deployment workflow (already configured in `.github/workflows/deploy.yml`).
5. Your website will be live in 1-2 minutes at:
   ```
   https://orondee.github.io/Test-Websites/
   ```

### Option B: Build & Push `dist` Branch

```bash
npm run build
npx gh-pages -d dist
```
